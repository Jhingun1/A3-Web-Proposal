M5Filter pattern: chips + sheetThe 2–3 most-used filters surface as chips (persona: decide fast); everything else (duration range, access, area) lives in “All filters” as a bottom sheet with apply/cancel — standard mobile pattern, no full page load. Chips and sheet share state.
M6Row densityMeta line = cost → duration → best time, same decision order as desktop. Rows are 96px+ tall: comfortable touch target without a details tap for the most common action (add). Long-press a row = “Details” (power-user shortcut).
M7Sticky strip persistsThe plan strip follows the user down the list so adding items always shows immediate, in-place feedback — the discovery→plan loop never leaves the screen.

M8Timeline, not tableDesktop rows become a vertical timeline with time dots — matches how people read a day on a phone. Reorder by drag (long-press + drag) or via the edit icon on each item; summary bar re-computes live.
M9Share-first footerOn mobile the share action is the biggest element in the page — the concept’s word-of-mouth loop (Jenna → friend). Link copy uses the system share sheet; PDF export secondary. No account wall before sharing.
M10Context of useDesigned for: standing, one thumb, outdoors (high contrast, large text, no small hover-only states), offline tolerance (plan page cached last-visited). Accessibility: 44px targets, WCAG AA contrast, text badges not colour-only.
Mobile-first rationale: All three personas plan on a phone; desktop wireframes (separate board) are the research/power-planning surface. Shared system: same chips, same cards, same plan model — only the layout shell changes.
